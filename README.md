💳 Bank Transaction Data Analysis

This project involves analyzing bank transaction data to study customer spending behavior and transaction patterns. The data was cleaned and explored using Python, followed by visual analysis of transaction types, amounts, channels, and customer occupations. Outlier detection techniques were applied to identify unusually high-value transactions, which can be useful for fraud detection and risk analysis. The project provides meaningful insights for banking operations and decision-making.

Technologies Used: Python, Pandas, NumPy, Matplotlib, Seaborn
